# 简历过筛 ResumePass

中英文双语 AI 简历优化站：JD 定向改写 + ATS 过筛评分。

## 一句话介绍

用户粘贴简历 + 岗位 JD，网站先做确定性 ATS 评分（不调 AI、免费），再按 JD 用 AI 改写（STAR + 量化、不编造），改完再评分看涨分，导出 PDF/Word。

## 技术栈

- Cloudflare 免费层：Workers + D1 + KV + R2
- AI：免费 Key（NVIDIA Nemotron / OpenRouter），后台可配模型 + Key + 规则，不改代码
- 双语：国内默认中文、国外自动英文（`/` 与 `/en/`）
